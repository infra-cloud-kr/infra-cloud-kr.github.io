우리의 미션
===========

infra-cloud-kr은 **OpenInfra(OpenStack)** 와 **Cloud Native(Kubernetes/CNCF)** 두 생태계를 연결하는 한국 커뮤니티입니다.

클라우드 인프라의 핵심 기술인 OpenStack과 Kubernetes는 서로 보완적인 관계에 있습니다.
우리는 두 생태계의 지식과 경험을 공유하고, 한국의 클라우드 인프라 기술 발전에 기여합니다.

- 오픈소스 클라우드 인프라 기술의 한국어 지식 공유
- OpenStack과 Kubernetes 생태계 간의 협업 촉진
- 한국 클라우드 엔지니어 커뮤니티 네트워크 구축

Linux Foundation
================

infra-cloud-kr은 `Linux Foundation <https://www.linuxfoundation.org/>`_ 산하 프로젝트들과 함께합니다.

`OpenInfra Foundation <https://openinfra.dev/>`_ 과 `Cloud Native Computing Foundation (CNCF) <https://www.cncf.io/>`_ 은
모두 Linux Foundation의 일원으로, 오픈소스 클라우드 기술의 발전을 이끌고 있습니다.
